================================================================================
                      AUTHENTICATION FLOW
================================================================================

1. User enters phone number (+94XXXXXXXXX)
2. App validates phone format and finds worker in Firebase
3. Firebase sends SMS OTP to phone
4. User enters 6-digit OTP code
5. App verifies code with Firebase
6. If successful:
   - Store worker ID in SharedPreferences
   - Store user role
   - Navigate to WorkerMainScreen
7. Dashboard loads with worker analytics
